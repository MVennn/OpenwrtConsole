> **一句话**：这一版把「只在一台设备上成立」的假设逐条去掉 —— 换一台路由器、换一种固件、换一个端口，页面与操作都还能用。

**令牌动作不再必然失败；无线、客户端、固件与软件包页也不再要求设备长成某一台机器的样子。**

## 本版内容

**概览**

- 调整 概览 —— WAN / WAN6 / LAN 按角色识别（接口名 → 默认路由 → 网卡名），接口不叫 `wan` 也能显示；实时流量跟随实际网卡（如 `pppoe-wan`）。
- 调整 概览 —— 客户端统计改为「无线 / 其他」，无线面板显示「射频数 · SSID 数 · 终端数」。
- 修复 概览 —— 代理状态显示 ShellCrash 实际的控制器端口，不再固定 9999。

**配置**

- 调整 无线配置 —— 2.4 GHz 信道扩到 1–13，5 GHz 补上 DFS 信道（52–144），带宽补 HE160 / VHT160 / EHT；切换频段时自动重置信道与带宽。
- 调整 系统设置 —— 路由器不提供时区列表时，内置时区补齐香港、新加坡、东京、伦敦、柏林、纽约、洛杉矶。
- 调整 首次配置 —— 没有无线硬件的设备不再被判为「未配置」；频段优先按驱动上报的频段与频率识别。
- 修复 防火墙配置 —— 端口转发的「命中流量」按外部端口匹配，内网端口不再造成错配。
- 修复 网络配置 —— 静态路由的「生效状态」在路由器不提供路由表时回退接口数据，不再永远显示未知。

**运维**

- 调整 软件包 —— 只有 opkg 的固件返回明确说明（控制台目前只支持 apk），不再显示空列表；apk 代理端口按 ShellCrash 实际混合端口探测。
- 调整 ShellCrash 设置 —— 端口区按运行时实际端口（mixed / redir / tproxy / dns / 控制器）检查，不再只看默认五端口。
- 调整 固件与备份 —— 官方镜像识别 `.bin` / `.img.gz` / `.itb`，手动上传接受 `.bin` / `.tar` / `.img` / `.gz` / `.itb`。
- 修复 固件与备份 —— SNAPSHOT、自编固件与非官方发行版只给风险提示，不再显示「已是最新」或「有更新」。
- 修复 系统设置 —— 没有 `chpasswd` 的固件回退 BusyBox `passwd` 改密码，两种工具都缺时给出可读错误。
- 修复 系统 —— 「系统」页的重启与「服务与运维」页一致，走一次性令牌。
- 调整 诊断 —— 超时按工具区分：ping 30 秒、DNS 15 秒、路由跟踪 120 秒、路由表与监听端口 10 秒。

**代理**

- 调整 代理 —— 主组按类型优先挑选（Selector → URLTest → Fallback → LoadBalance），区域组不会因为名字排到前面。
- 调整 代理 —— 页面显示 ShellCrash 实际的控制器端口，文案改为「ShellCrash 核心」。
- 修复 代理 —— 缺少 `curl` 时返回明确错误，不再等到超时后给出空应答。

**界面**

- 调整 无线 —— 一个射频下的全部 SSID 合并统计终端、信号与流量；SSID 数量按实际统计；信道优先显示驱动上报值；频段筛选按设备实际频段生成，6 GHz 独立配色。
- 调整 客户端 —— 无线频段统计按实际数据汇总；原「有线客户端」改为「其他客户端」（仅有 DHCP 租约、未关联无线）。
- 调整 监控与流量 —— 累计流量优先取 WAN，找不到 WAN 才合计全部接口并标注「可能重复计数」。
- 调整 网络 —— 网络设备类型补充 `ppp` / `gre` / `sit` / `6rd` / `ip6tnl` 等虚拟接口识别。
- 调整 文档 —— 根 README 收敛为面向用户的说明；部署文档补充运行时依赖与「同时更新 dist 与 CGI」的要求。
- 修复 登录 / 侧栏 —— 未安装 LuCI 的固件隐藏 LuCI 入口并提示「LuCI 未安装」；HTTPS 提示按实际协议显示。

**修复**

- 修复 特权动作 —— 令牌校验读错变量，改密码 / 重启 / 恢复出厂 / 恢复备份全部报「令牌无效」。
- 修复 在线状态 —— 新增邻居表读取（IPv4 ARP / IPv6 NDP），静态地址设备与有线在线状态有据可查。
- 修复 客户端 —— 静态租约的在线状态按无线关联表与邻居表判定，静态 IP 设备也能识别，未过期租约不再当作在线。
- 修复 无线页 —— 多个 SSID 的终端、信号与流量按射频合并，统计不再只算第一个 SSID。
- 修复 无线终端列表 —— 取不到设备名时按 iwinfo 与 sysfs 探测，不再猜 `phy0-ap0` / `phy1-ap0`。
- 修复 网络 —— 网络设备的错误与丢包计数在字段缺失时按 0 显示，不再出现 `NaN`。
