> **一句话**：控制台的**首版** —— 从只读看板到能改配置、能装软件、能刷固件的完整替代品。

**控制台可以读写防火墙、无线与网络配置了；软件包管理、固件刷写、备份恢复与 ShellCrash 设置页也都能用了。**

## 本版内容

**概览**

- 新增 概览 —— 设备型号、固件、WAN/LAN/IPv6、运行时间、实时流量曲线、接口、无线、最近客户端、当前代理出口。

**只读页面**

- 新增 网络 —— WAN / WAN6 / LAN 摘要、全部接口表、网络设备计数与错误统计。
- 新增 无线 —— 射频、SSID、信道、发射功率、平均信号、关联终端信号与链路速率。
- 新增 客户端 —— DHCP 租约与无线终端的合并视图，支持搜索与有线/无线筛选。
- 新增 防火墙 —— 安全区域策略、端口转发、出站规则、流量卸载状态。
- 新增 DNS —— dnsmasq 上游、地址池、静态租约、当前租约、自定义主机名。
- 新增 代理 —— ShellCrash 运行状态、策略组、当前出口、活动连接，可直接切换策略组节点（切换前有二次确认）。
- 新增 诊断 —— ping、DNS 解析、路由跟踪、路由表、监听端口，命令在路由器本地执行。
- 新增 系统 —— 固件与内核信息、内存/存储/交换分区、系统日志、重启。

**配置（可写）**

- 新增 网络配置 —— 配置页 → 网络；接口与静态路由可改，改完应用生效。
- 新增 无线配置 —— 配置页 → 无线；SSID、射频、信道与发射功率可改。
- 新增 防火墙配置 —— 配置页 → 防火墙；区域、端口转发、出站规则、流量卸载可改。
- 新增 系统设置 —— 配置页 → 系统；主机名、时区、地址池、静态租约与管理员密码可改。

**运维**

- 新增 软件包 —— 配置页 → 软件包；apk 已装列表、仓库检索、安装与卸载、索引更新与全量升级。
- 新增 固件与备份 —— 配置页 → 固件；上传固件并刷写，配置备份与恢复。
- 新增 监控与流量 —— 配置页 → 监控；资源曲线、接口速率、客户端在线与速率历史。
- 新增 服务与运维 —— 配置页 → 运维；服务启停与开机自启、进程、存储挂载、连接跟踪、备份、重启、恢复出厂。
- 新增 ShellCrash 设置 —— 配置页 → ShellCrash；服务启停与开机自启、核心设置、覆写文件启停、订阅概览、运行日志与自愈状态。
- 新增 首次配置向导 —— 设备尚未配置时，引导设置密码、时区、无线与上网方式。

**界面**

- 调整 设计语言 —— 整体改用 art-design-pro 的视觉基线：白色卡片 + 浅灰页面底、12px 圆角、极轻阴影、深浅色双主题、左侧导航 + 顶部栏。
- 调整 移动端 —— 窄屏下侧栏改为抽屉，表格切换为卡片列表，触控目标不小于 36px。
- 调整 可访问性 —— 正文与辅助文字对卡片底对比度不低于 4.5:1，状态不只依赖颜色，键盘焦点有品牌色描边。

**修复**

- 修复 首屏体积 —— Element Plus 从全量引入改为按需引入，首屏从 1.42 MB 降到约 415 KB（gzip 约 117 KB）。
- 修复 更新后白屏 —— 部署保留上一代资源，旧标签页不会因为资源被删而白屏；入口资源失效时页面会自动重新加载。
- 修复 无线终端列表为空 —— 无线终端改由路由器本地读取，不再依赖可能返回空列表的接口。
- 修复 登录后立刻掉线 —— 改用自建的会话标识，不再复用浏览器拒收的会话 Cookie。
