遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/OpenwrtConsole/issues/new/choose) 反馈 —— 请附上设备与固件、控制台版本、出问题的页面与浏览器报错。

## 本版内容

**客户端**

- 新增 设备类型识别 —— 无线客户端页新增「类型」列；新设备首次接入时自动识别一次（端口 / miIO / 小米电视与网关 / SSDP / mDNS），配合 OUI 厂商表给出手机 / 平板 / 电脑 / 电视 / 摄像头 / 打印机 / NAS / 智能家居；结果按 MAC 缓存 7 天，IP 变化自动重测。

**ShellCrash**

- 新增 内核更新检测 —— 并排显示已安装内核、GitHub 最新 mihomo 与 ShellCrash 版本表；有新内核或版本表落后时给出说明与更新路径。只检测，不下载、不替换。
- 调整 防火墙区域 —— 从数字输入框改为带语义说明的下拉（1..5），不再需要记编号。

**软件包**

- 修复 更新仓库索引 —— 每次写操作都被判成失败的问题（CGI 返回 `job_id`、页面读 `jobId`），索引现在能正常更新。
- 修复 仓库列表 —— 支持 50 / 100 / 200 分页，1.1 万个包不再只看到字母序前 400 个。
- 优化 解析缓存 —— 整表解析成按行池缓存，翻页与检索从约 4 秒降到 0.2–1 秒。
- 修复 重启后仓库为空 —— `/tmp` 是内存盘，打开仓库会自动补建索引；升级提示不再因缓存缺失恒显示「已是最新」。

**界面**

- 修复 深色模式 —— Element Plus 语义色背景不再整片发白（`el-alert` / `el-tag` / `el-message`）。
- 修复 代理组卡片 —— 测速后不再横向溢出。

**安全**

- 修复 备份 / 恢复路径 —— 拒绝 `..` 穿越与非法文件名；`backup-create` 此前无令牌即可调用。
- 修复 修改系统时间 —— 只接受 2020–2100 的 Unix 时间戳，避免把会话与令牌一次性全判过期。
- 修复 登录请求体 —— 缺失 `CONTENT_LENGTH` 时也限制读取量，超出回 413。
- 修复 危险动作连点 —— 刷写、上传刷写、恢复备份、保存、切节点补上 in-flight 守卫，不再重复取令牌或并发写 UCI。
