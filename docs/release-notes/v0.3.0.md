> **一句话**：侧栏从 18 个平铺入口收敛成 10 个工作区，一批无效按钮、错位入口与错误状态被修掉；路由器端的配置应用与日志转义也不再空转。

**侧栏改成 10 个工作区；DHCP 与系统设置的保存真正生效；刷新、重启、草稿时间、连接指示灯等一批无效或错位的行为修好了。**

## 本版内容

**概览**

- 修复 代理卡片 —— 概览页；离开页面后不再继续跑预热定时器，后台不再有无谓请求。

**配置**

- 修复 系统设置 —— 「DHCP 与系统设置」页；静态租约、主机名、时区、syslog 大小保存后真正生效，不再出现「保存成功但配置没变」。

**运维**

- 修复 页头刷新按钮 —— 软件包、DHCP 与系统设置页；点击后真正重读列表或重载配置，不再只转圈；诊断页与首次配置向导没有可轮询的数据，直接隐藏按钮。
- 修复 重启按钮 —— 系统页；指令发出后无论成功失败都复位，不再一直停在加载中。
- 调整 ShellCrash 服务启停 —— 服务与运维页；与其它特权动作一致，执行前需要确认。
- 修复 固件刷写 —— 固件与备份页；固件信息里含制表符等控制字符时，应答不再变成非法 JSON。
- 修复 诊断输出 —— 诊断页；路由表等多行命令的第一、二行不再粘在一起。

**代理**

- 修复 切换失败的提示 —— 代理页；错误消息含引号时不再让整个应答变成非法 JSON。
- 调整 代理组列表 —— 代理页；组名与节点名过长时在各自列内截断，下拉框可收缩到 140px，列表在卡片内滚动，不再把左栏拉长或横向溢出。

**界面**

- 调整 侧栏 —— 18 个平铺入口收敛为 10 个工作区（概览 / 监控 / 网络 / 无线 / 客户端 / 防火墙 / 代理 / 系统 / 运维 / 诊断）；同一任务的「看状态」与「改配置」用标签页切换，路由、深链接与浏览器前进后退保持不变，710px 高度内无需滚动。
- 修复 工作区标签栏 —— 不再压住页面标题；页头固定为 64px，标签栏改为不透明背景，滚动时内容从下方干净穿过。
- 修复 首次配置入口 —— 从侧栏移到系统页「更多设置」，不再把整页切到布局外的向导。
- 修复 侧栏连接指示灯 —— 断网时不再显示绿色，跟随浏览器的在线 / 离线状态。
- 修复 草稿时间戳 —— 恢复本地草稿后，「修改时间」不再总是当前时间。
- 清理 重复入口 —— 网络 / 无线 / 系统页头与工作区标签重复的主按钮移除，页内文字链接保留。
- 对齐 双栏卡片底部 —— 代理页「运行配置」、概览页摘要卡；右栏最后一张卡片的底边与左侧较高卡片对齐。

**开发工具**

- 新增 本地 mock 路由器 —— `tools/mock-router.mjs`；没有路由器与 root 密码也能跑完整界面，只监听 `127.0.0.1`，不参与构建，用法见 [CONTRIBUTING](https://github.com/MVennn/OpenwrtConsole/blob/main/CONTRIBUTING.md#本地-ui-开发不需要路由器)。
- 调整 开发文档 —— 根 README 的「本地开发」与 CONTRIBUTING 补 mock 用法。

**优化**

- 优化 前端内存 —— 概览 / 无线 / 客户端 / 网络 / 系统 / 监控 / 代理页的 ubus 返回改为浅层响应式，图表配置不再每轮深度遍历。
- 优化 路由器端 —— 配置与日志的 JSON 转义改为批量替换、ShellCrash 日志数组一次 awk 输出、overrides 统计改用 `date -r`、日志读取少一个进程、软件包缓存不再留孤儿文件；真机 200 KB 输入的转义从 20 秒以上降到 1 秒内，200 行日志从约 400–600 个进程降到 1 个。

**仓库**

- 调整 仓库 —— 文档自检跳过本地 `.work/` 与 `.codegraph/`；`.gitignore` 补 `__pycache__/` 与 `*.py[cod]`，删除失效条目。
