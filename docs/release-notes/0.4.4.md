**本版只改文档与依赖说明：控制台页面、CGI 与产物与 0.4.3 完全相同；唯一实质新增是「精简固件要单独装 `ucode`」。**

遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/OpenwrtConsole/issues/new/choose) 反馈 —— 请附上设备与固件、控制台版本、出问题的页面与浏览器报错。

## 本版内容

**部署与依赖**

- 新增 运行时依赖 ucode —— `modern-login` / `modern-data` / `modern-read` 三个 CGI 的解释器；随 `luci-base` 装上，无 LuCI 的精简固件要单独 `apk add ucode`，缺它这三个页面取不到数据。
- 新增 探测助手安装位置 —— 部署脚本把 `modern-probe.lua` 装到 `/usr/lib/modern/probe.lua`（不在 `/www` 下，浏览器访问不到）；它另需 Lua 的 `nixio`，缺它只有主动指纹探测降级。

**门面与文档**

- 调整 门面 —— 根 README 写清「任意 OpenWrt」的确切口径（uhttpd + ubus/rpcd 可用即可、不限发行版）、浏览器要求（支持 ES2020）、会话 1 小时、部署脚本的环境变量与本地开发换设备的方式。
- 调整 架构说明 —— 运行时依赖段补 `ucode`；「10 个通道」那张表写明是 11 行通道拆分、`modern-probe.lua` 不计入 9 个 CGI。
- 调整 部署文档 —— 运行时依赖表补 `ucode` 一行，部署步骤补装 `modern-probe.lua` 那一步。
- 调整 版本规范 —— §4 记下当前版本与本版性质，Release 说明链接此前落后一版（指 0.4.2），本版起指向 0.4.4。
- 调整 历史契约 —— v3 契约转为历史文档，写入规范以 `WRITE-LAYER.md` 为准；`uci.apply` 标注为历史误写，现役动作名是 `uci-apply`。
- 修复 写入层条目数 —— 文档索引里「七类动作」改为与现役一致的 5 类。
- 修复 链接写法示例 —— 文档规则里的示例链接改为行内代码，不再被当成真实目标点验。
- 修复 跨仓出处 —— 踩坑文档与敏感信息扫描脚本头注释里的仓名由 ZcodeAIModels 改为 ModelBus。
- 调整 快照表述 —— 维护说明里「本仓是上游快照」改为「源于 2026-10-20 初版快照、此后已独立演进」。
- 调整 记忆目录 —— `memories/` 明确为项目记忆的 git 快照，长文正本在记忆库，冲突以代码为准。
